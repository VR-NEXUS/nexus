    Discovery

    The brief, the audience, and the space the brand has to occupy.

    1. The brief

      What the brand has to do, written in the client’s own words before a pencil moves.

    2. The read

      What the category already looks like, and the one position nobody is holding.

    3. The space

      Brief, audience and gap settled on a single page, so the next step has a floor.

    You get A written brief, a competitor read, and one page that names the space.

    02 / ProcessConcept

    Concept

    Three directions, each shown in context, so the choice is a decision and not a guess.

    1. Three routes

      Three directions, not thirty. Each drawn far enough to be judged, not admired.

    2. Marks by hand

      The wave, the circle and the wordmark, tested on paper before a single vector.

    3. Drawn out

      Each route worked up at full size, so its proportions are decided on paper.

    You get Three routes on real surfaces, so the pick is a decision.

    03 / ProcessBuild

    Build

    The chosen direction becomes a documented system anyone can apply.

    1. Set to a grid

      The chosen mark is rebuilt on a measured grid, so it holds at any size.

    2. Type and spacing

      A type scale, spacing steps and export rules, written down as the system is drawn.

    3. Proofed on press

      Every mark is checked small, on a phone, and in a single colour before it ships.

    You get A documented system: grid, type scale, spacing, export rules.

    04 / ProcessDeliver

    05 / Questions

    Before you write

    The six things people ask before the first call.

    What does a project cost?

    Fixed per project, not hourly. After the discovery call you get one number covering strategy, design and the final files.

    That number is the whole fee. No hourly drift, no surprise invoice, because the scope is written down first.

    How long does a project take?

    A logo system takes two to three weeks. A full identity with a website runs four to six weeks.

    The clock starts when the brief is signed and the first payment clears. Your own feedback is the one variable I cannot plan.

    What do I actually receive at the end?

    Vector, PNG and PDF masters, a type and colour specification, and the source files. Nothing is locked to this studio.

    It arrives in one named folder with a short handover note, so the next designer or printer needs no call.

    How many revisions are included?

    Three rounds at concept, two at refinement. A round shapes the chosen direction, it does not restart it.

    A round that turns into a new direction is a new phase with its own price, agreed before the work starts.

    Do you build the website as well?

    Yes. Built by hand in HTML, CSS and JavaScript, tested on real devices and handed over with the source.

    No page builder, no locked template. You get the files, a short guide, and a site that runs on a mid range phone.

    Can you work with the brand I already have?

    Often, yes. If the identity is sound, the work extends it. If it is not, you will hear that first.

    I audit the mark, the type and where both are used, then say plainly whether to keep, refine or replace it.

    Still unsure? Send the question directly and it gets a straight answer.
